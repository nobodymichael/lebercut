# LEBERCUT — Carbon Workspace 0.3

Rozpakuj ZIP do katalogu głównego istniejącego repozytorium lebercut, nadpisując pliki. Nie usuwaj innych zasobów. Bez zmian w silniku engine.js, zapisie projektów i wydruku A4. npm test uruchamia sześć zestawów testów silnika.

Szybkie dodawanie: 1500x300x2 1D2K W, Enter dodaje, Shift+Enter pozwala wprowadzić kolejną linię. Wymiary i ilość edytujesz bezpośrednio w tabeli; Enter lub utrata fokusu zatwierdza. Kliknięcie kodu okleiny otwiera szczegółowy edytor. Ustawienia materiału są zwijane. Na ekranach poniżej 900 px (lub dotykowych poniżej 1100 px) wyświetlany jest ekran Desktop Only; większe tablety pozostają dostępne. Zmiana szerokości może wymagać odświeżenia. Ograniczenie jest interfejsowe, nie jest zabezpieczeniem dostępu.

Własny manifest i ikony, wspólny Donate, menu ekosystemu, większe intro z oryginalnym logo konturowym. Testowano w osadzonym Chromium: dodanie tekstowe, edycję, dodanie formularzem i ekran blokady telefonu. Nie sprawdzono fizycznego druku, Safari, instalacji PWA ani publikacji na GitHub Pages.
